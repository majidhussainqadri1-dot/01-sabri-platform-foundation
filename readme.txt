== Description ==

This plugin is a governance and compatibility plane. It does not create a second public shell, feed, profile, identity system, Security Center, notification owner, or search/discovery/ranking backend.

Version 2.0.1 is the current repository candidate. Its schema remains 1.2.0 and its contract version remains 2.0.0. It closes the live-discovered Safe Repair/reconciliation ownership bypass: `spf_page_map` and `spf_founder_user_id` are now exclusively cut over by the guarded Reconciler after canonical File 20/File 21 acknowledgement and reversible receipts. Production use still requires the separate Hostinger staging, Founder-acceptance, deployment and operational gates in STAGING-ACCEPTANCE.md.

== Installation ==

1. Verify the exact candidate HEAD, package SHA-256 and SOURCE-CHECKSUMS.sha256.
2. Freeze the current staging reality before changing anything.
3. Install only on isolated staging after independently verified backup/restore evidence.
4. Activate as an authorized operator.
5. Run the redacted System Check and schema/index verification.
6. Register real owner manifests/adapters from companion modules; do not seed placeholder truth.
7. Confirm the Legacy Reconciliation Dry Run has valid canonical owner plans and no blockers before any apply action.
8. Complete STAGING-ACCEPTANCE.md before any production approval.
