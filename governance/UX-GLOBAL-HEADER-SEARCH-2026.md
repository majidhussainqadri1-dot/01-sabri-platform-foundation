# Global Header: Exact Left-Corner Logo and Search Group

## Explicit Founder clarification — 21 October 2026

The **logo and the main global search together form one left-anchored group** in the website header. They must not be split, centered, or moved to opposite sides of the page.

**Exact horizontal order, from the browser's left edge:**

1. **Top-left corner:** Sabri Homeopathy logo, located at the leftmost practical position within the header with only the necessary minimal edge padding.
2. **Immediately to the logo's right:** the main website-wide search bar, with minimal consistent spacing.
3. **All other header elements:** outside this left-corner brand-and-search group.

The left edge refers to the **physical left side** of the visible website on both LTR and RTL language interfaces. The entire two-control group must remain positioned on the left. Do not interpret "search to the right of logo" as moving the search to the right edge or center of the whole page.

For mobile widths, keep the logo in the left corner and a search icon/button directly to its right when the full field cannot fit; opening the icon must invoke the same primary search.

## Interaction

- Clicking/tapping the logo on another page navigates to the canonical homepage.
- Clicking/tapping the logo while already on the homepage reloads the page.
- The search box/icon opens or runs the central site-wide File 26 search.

## Ownership and acceptance

File 20 owns global header placement, File 25 owns responsive visual design, and File 26 owns search functionality. Acceptance must verify leftmost group alignment, logo-then-search order, small spacing, mobile behavior, LTR/RTL physical-left positioning, keyboard accessibility, navigation and homepage reload.
