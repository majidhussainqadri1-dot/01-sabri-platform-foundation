Canonical File 01-B governance, registry, dependency, route, privacy, event, health, reconciliation, repair and release-evidence runtime for the Sabri Social Homeopathy Platform.

== Description ==

This plugin is a governance and compatibility plane. It does not create a second public shell, feed, profile, identity system, Security Center, or search/discovery/ranking backend.

Version 1.2.0 adds final central-plan harmonization: 00–26 registry governance, stricter File 00 claim binding, deterministic dependency/contract bounds, event privacy classification, fail-closed feature activation evidence, exact index verification, safer reconciliation, purge hardening, and deeper automated QA. Production use still requires the separate staging and Founder-acceptance gates in STAGING-ACCEPTANCE.md.

== Installation ==

1. Verify the package SHA-256 and SOURCE-MANIFEST.sha256.
2. Install only on isolated staging after verified backup/restore evidence.
3. Activate as an authorized operator.
4. Run the redacted System Check and schema/index verification.
5. Register real owner manifests from companion modules; do not seed placeholder truth.
6. Complete STAGING-ACCEPTANCE.md before any production approval.
