# File 01 — Sabri Platform Foundation 1.1.0

This repository implements **File 01-B**, the governance/runtime foundation defined by `SSH-F01-PLAN-2026-v1.0` under the Definitive Master Plan v3.0.

## Canonical boundary

File 01 owns module/contract/route registries, dependency readiness, safe activation/upgrade conventions, redacted System Check, release evidence, privacy lifecycle for its own records, legacy reconciliation orchestration, owner-scoped repair and guarded purge governance. It does **not** own membership identity (File 00), global shell/navigation (File 20), Home/News/feed (File 21), Security Center assurance (File 24), public visual/profile experience (File 25), or search truth (File 26).

## Release truth

Version 1.1.0 is a corrective source/package candidate. Repository CI can prove source, WordPress/MySQL runtime, migration, concurrency and deterministic-package gates within its automated scope. Hostinger staging, real companion-module adapters, browser/device/accessibility acceptance, backup/restore rehearsal, Founder approval, production deployment and continuous operations remain separate evidence statuses.

## Security changes in 1.1.0

- Structured, short-lived File 00 authorization claims and separation of duties.
- No generic Administrator release, Founder or purge authority.
- Atomic idempotency reservation before mutations.
- Evidence-enforced release state machine.
- Full shadow-table activation/upgrade compensation.
- Canonical-owner reconciliation receipts and exact metadata rollback.
- Structured backup/restore plus File 24 assurance before purge.
- WordPress privacy exporter/eraser and scheduled retention without breaking the audit chain.
- Actual WordPress/MySQL runtime CI in addition to source assertions.
