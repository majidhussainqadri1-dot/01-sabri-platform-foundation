# File01 V12.3 — WordPress 7.0.1 and current-core CI baseline parity, source-only

**Date:** 16 Nov 2026. **Requirement:** F01-NFR-009 compatibility verification. **Scope:** disposable GitHub Actions test environment, not Hostinger Staging or Live.

## Evidenced gap and negative control

The source CI workflow had PHP 8.1/8.3 static/source jobs, but a single WordPress/MySQL runtime job installed whichever latest WordPress core `wp core download` provided, without a version pin. That cannot independently verify the Master Plan's specifically required WordPress **7.0.1 / PHP 8.3** baseline.

Added three source-quality assertions before any workflow change at **red commit** `d5528a95c0976caf832c39c268aa9f3cddd3fc74`. GitHub Actions Run **43805570794** failed both PHP 8.1 and 8.3 source quality with exact expectations: missing 7.0.1/current matrix, missing pinned installation, missing observed core version. This is **one QA coverage gap**, not a newly proven production software failure.

## Controlled correction

The existing WordPress/MySQL runtime job is now a two-lane matrix: `wp_version: ['7.0.1', 'current']`. Pinned lane explicitly downloads `--version=7.0.1` and verifies the installed core version equals `7.0.1`; current lane retains the pre-existing default-current behavior. Each lane executes the full disposable WP/MySQL smoke, plugin activation, concurrency, guarded schema/upgrade and purge tests. PHP 8.1/8.3 source, deterministic package and exact artifact SHA checks remain unchanged, and packaging depends on both WordPress lanes succeeding. Once green, expected job count becomes **five**: two PHP source + two WordPress runtime + one deterministic package.

The 7.0.1 lane is a **test fixture only**; no change to the live site's WordPress version or any live deployment. Exact current WordPress version is logged dynamically rather than guessed. A green CI is repository source/runtime evidence only, not proof of installed Hostinger compatibility, live parity, or the 43 semantic requirements' independent acceptance.
